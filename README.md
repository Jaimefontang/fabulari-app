# fabulari-app
Proyecto Fin de Ciclo DAM 2026.  Fabulari es una app Android desarrollada en Flutter que genera cuentos terapéuticos personalizados para niños de 3 a 10 años usando inteligencia artificial. Combina Gemini, Imagen 3.0 y Google Cloud TTS con un backend en Supabase para crear historias únicas adaptadas a la situación emocional de cada niño.
